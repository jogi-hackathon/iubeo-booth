JOGI HACK 2026 最終発表会（10/17）の IUBEO ブースで使う道具。

道具

  • 観測 /observer/

    カメラに映った人を、ゲームのプレイヤーと同じ白い骨格だけで映す。iPad Pro に出す。カメラを使うので、許可を求められたら許可する。
  • 伝票メーカー /slip/

    ゲームの依頼伝票と同じ見た目で中身を書き換え、PNG か PDF にする。スマホで開いて Phomemo T02 で刷る。
  • ブース模型 /mock/

    六角形の机に、プレイヤー・iPad・ロゴ・ファイルのカード・伝票差しを実寸で置いた 3D 模型。置き方を変えながら回して見られる。
  • 印刷データ GitHub

    ロゴ（A3）、ファイルのカードとパネル、お題の三角紙。白黒・100%（実際のサイズ）で刷る。刷り方は README にある。
