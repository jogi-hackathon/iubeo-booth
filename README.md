# iubeo-booth

IUBEO の展示ブースで、前を通る人を MediaPipe のランドマークだけで映すモニター。
映像は表示せず、ゲーム内のプレイヤーと同じ白い骨格だけを描く。画面の文字は IUBEO のロゴだけ。

公開版: https://jogi-hackathon.github.io/iubeo-booth/ （`main` に入ると GitHub Actions で自動デプロイ）

ブースの 3D 模型: https://jogi-hackathon.github.io/iubeo-booth/mock/ （`public/mock/index.html`。机・モニター・ロゴ・ファイルのパネルを実寸で並べ、置き方を変えながら回して見られる）

## 起動

```sh
pnpm install
pnpm fetch:model   # wasm とモデルを public/mediapipe に置く（会場をオフラインで動かすため）
pnpm dev           # http://localhost:5173
```

`fetch:model` をしていなければ CDN から読み込む。Chrome 推奨。

## URL パラメータ

| パラメータ | 内容 |
| --- | --- |
| `?demo` | カメラを使わず、合成した歩行者で動かす（リハーサル・確認用） |
| `?model=full` | 精度の高いモデルを使う（既定は `lite`） |
| `?people=5` | 同時に検出する人数の上限 |
| `?cutoff=0.8` | 静止時のならし具合 (Hz)。小さいほど震えが減る |
| `?beta=6` | 速い動きへの追従。大きいほど遅れが減る |

## キー操作

| キー | 内容 |
| --- | --- |
| `f` | フルスクリーン切り替え |
| `d` | 調整用の表示（fps、MediaPipe が返した骨格の数 `raw`、重複を除いた数 `tracked`、カメラ映像の小窓） |

## ファイルのパネル（入稿データ）

ゲーム内のファイル（Web Search・画像生成・Write）を、ブースに掛けるパネルにした印刷データ。
形と寸法比は `iubeo/frontend/src/items/fileModel` のモデルをそのまま写していて、3 枚とも同じ倍率にしてある。

| ファイル | A4 版 | A2 版 |
| --- | --- | --- |
| Web Search | 218.0 × 178.0 mm（A4 横） | 479.6 × 391.6 mm |
| 画像生成 | 216.0 × 176.0 mm（A4 横） | 475.2 × 387.2 mm |
| Write | 176.0 × 216.0 mm（A4 縦） | 387.2 × 475.2 mm |

- `print/png/file-panel-a4-*.png`：A4 に 1 枚で刷る PNG（300 dpi、3508 × 2480 px）。家やコンビニのプリンタで刷れる
- `print/file-panels-a4.pdf`：上と同じ A4 版の PDF
- `print/file-panels-a3-tiles.pdf`：A2 のパネル 1 枚を A3 の 2 枚に分けたもの（全 6 ページ）
- `print/file-panels-a2.pdf`：A2 に 1 枚で刷るもの（全 3 ページ）

作り直すときは `pnpm print:panels`。PNG は macOS の PDFKit で描くので、macOS でだけ書き出される。

### A4 版の作り方

1. 白黒、**100%（実際のサイズ）** で刷る。「用紙に合わせる」「フチなし」は切る
2. 紙の下にある 50 mm の目盛りを定規で測り、縮んでいないか確かめる
3. トンボで切り、白いボードに貼る

外周は黒を 3 mm 外まで塗り足してあるので、トンボより少し外を切っても白は出ない。

### 手のひらのカード（配る用）

ゲームの中のファイルと同じ大きさのカード。来場者に配る想定。

- `print/png/file-cards-a4-search.png`・`-image.png`・`-write.png`：A4 縦、300 dpi。同じ種類が 4 枚ずつ並ぶ
- `print/file-cards-a4.pdf`：上の 3 枚をまとめた PDF

| ファイル | 大きさ |
| --- | --- |
| Web Search | 109 × 89 mm |
| 画像生成 | 108 × 88 mm |
| Write | 88 × 108 mm |

名刺（91 × 55 mm）よりひと回り大きい。Web Search と画像生成は紙の上で 90° 回して並べてあるので、切ったあとに向きを戻す。
刷り方はほかと同じく、白黒、100%（実際のサイズ）。トンボの線はカードの並び 1 列・1 行ぶんを通っているので、定規を当てて端から端まで切れる。厚めの紙（ケント紙や名刺用の厚紙）に刷ると、カードらしくなる。

### A3 分割版の作り方

1. A3、**白黒**、**100%（実際のサイズ）** で刷る。「用紙に合わせる」は切る。Write の 2 枚は A3 横向き
2. 刷れたら、紙の下にある 50 mm の目盛りを定規で測り、縮んでいないか確かめる
3. A（1/2）はトンボで外周を切る。継ぎ目の側は切らずに、のりしろ（12 mm）を残す
4. B（2/2）は、継ぎ目の側も含めてトンボで全部切る
5. A をボードに貼り、B を A ののりしろに重ねて貼る。B の端は、A の余白にある破線の印に合わせる

## ロゴ（入稿データ）

`iubeo/docs/assets/iubeo_logo.svg` を A3 1 枚に刷る印刷データ。100均のボードに貼って立てる想定。

- `print/png/logo-a3.png`：A3 横、300 dpi の PNG
- `print/logo-a3.pdf`：上と同じ PDF

ロゴは 350 × 103 mm。トンボの位置で切ると、白い余白 20 mm 付きの 390 × 143 mm のカードになる。A3 の紙をそのままボードに貼ってもいい。
刷り方はファイルのパネルと同じく、白黒、100%（実際のサイズ）で、「用紙に合わせる」は切る。作り直すときは `pnpm print:logo`。
